# Проверка сборки 0.3.0 — модульная архитектура

Среда сборки: Linux, Python 3.12; не Windows.

Python/API: **13 тестов, успешно**. React: **6 компонентных тестов, успешно**. TypeScript и production-сборка Vite — успешно.

- 17 подразделений и 166 сотрудников в каждом тестовом источнике.
- 28/29 дней в феврале невисокосного/високосного года.
- Одинаковые ключи после очистки пробелов и регистра; различение е/ё.
- Остановка при несовпадающем периоде и дублировании ФИ.
- Распознавание неполных/некорректных интервалов и ошибочного итога дня.
- 5146 дневных записей за август; совпадение месячной суммы с детализацией.
- В аналитическом JSON нет исходных имён; XLSX восстанавливает имена, а обезличенная выгрузка оставляет EMP-ключи.
- Будущие дни и удалёнка не превращаются в неявки.
- API: отказ без авторизации, вход, предварительный просмотр, импорт и экспорт.
- Руководитель HR получает 4 сотрудников; чужой отдел не выгружается; импорт запрещён.
- Экспорт учитывает поиск сотрудника. Личный кабинет получает одну запись; аудитор получает псевдонимы.
- Корневой URL выдаёт React HTML; файл собранного JavaScript доступен через FastAPI.

Дополнительные проверки 0.3.0: изоляция экземпляров приложения; валидация входной схемы; отказ в выдаче исходников через HTTP; сохранение предыдущего снимка при сбое публикации нового; чтение формата хранения 0.1/0.2; отсутствие зависимостей домена от FastAPI, Excel, сервисов и инфраструктуры.

React проверен командами `npm run build` и `npm test`. Компонентные тесты выполняются в jsdom: приём XLSX через drop; отказ для нескольких файлов и неподдерживаемого формата; отправка FormData с двумя файлами и блокировка повторного нажатия; сочетание фильтра и поиска; взвешенный KPI и пустой знаменатель; ошибка входа без открытия рабочего пространства. Эти тесты не являются реальной браузерной проверкой мышью.

Python-проверка: `python -m unittest discover -s backend/tests -t . -v`. Алгоритмы перенесены из core.py в доменные модули, сервис сверки и Excel-адаптеры; тестовые XLSX сохранены. Входные XLSX ранее открыты программно и визуализированы по верхним диапазонам; в 0.3.0 оформление файлов не менялось.

Не выполнены: запуск на Windows, визуальная проверка браузера, реальный drag-and-drop мышью, отправка на физический принтер, проверка всех страниц в настольном Excel. Эти проверки включены в пользовательскую приёмку Steps.md. Результат не является подтверждением промышленной готовности или полной проверки безопасности.
