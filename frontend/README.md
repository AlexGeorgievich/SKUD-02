# Frontend

> В ветке `feature/hr-lifecycle-admin` frontend содержит модули `features/hr`, `features/personnel` и `features/admin`. Актуальные сценарии: [../docs/CURRENT_STATE.md](../docs/CURRENT_STATE.md).

Из этой папки: `npm ci`, `npm run build`, `npm test`. Для автоматической пересборки: `npm run watch`; страницу обслуживает Python на 127.0.0.1:8000.

| Каталог | Назначение |
| --- | --- |
| src/app | Приложение, сессия, рабочее пространство и навигация |
| src/features/auth | Вход |
| src/features/import | Загрузка пары Excel и preview |
| src/features/records | Табличные представления |
| src/features/analytics | Дашборд и агрегаты отображения |
| src/features/audit | Журнал |
| src/shared/api | HTTP-клиент и скачивание |
| src/shared/ui | Общие компоненты и пагинация |
| src/shared/types.ts | Контракт API |
| src/shared/styles | Тема и адаптивное оформление |
| src/tests | Компонентные тесты |
| dist | Готовая сборка, включена в релизный ZIP |

Зависимости: app → features → shared. Сервер остаётся источником проверки прав и расчётных правил. Старый static/react больше не используется.

`src/features/analytics/BiDashboard.tsx` собирает BI-дашборд: KPI, Treemap структуры офиса и плана, динамику по дням, подтверждение офисных дней, тепловую карту замечаний и распределение часов присутствия. Тепловая карта строится по полному календарю загруженного месяца; цветная ячейка открывает общий `Modal` с исходными строками соответствующих отдела и даты. Расшифровка не классифицирует отсутствие регистрации как прогул.

В HR-карточке фамилия, имя и отчество вводятся раздельно, а ФИО только для чтения формируется из фамилии и имени. Личные и рабочие поля разнесены по согласованным вкладкам; даты используют календарь, контакты проверяются по формату, фото загружается через авторизованный API. Юридическое лицо, офис, отдел, должность, пол и формат работы выбираются из справочников, их CRUD доступен только admin во вкладке «Администрирование → Справочники». Реестр показывает метрику «Офис», кнопку добавления после поиска и однострочную компактную полосу отделов с прокруткой при нехватке ширины.

В разделе загрузки есть месячный поток Plan/СКУД/СК: preview показывает варианты КУС, неизвестные и неоднозначные строки блокируют apply до ручного выбора. После apply можно сформировать и увидеть сводку месячного расчёта по UUID. Legacy-импорт пары Excel сохранён.
